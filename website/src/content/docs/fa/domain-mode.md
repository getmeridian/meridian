## حالت دامنه چه می‌افزاید

```
meridian deploy 198.51.100.10 --domain vpn.example.com
```

بدون دامنه هم، خروجی از قبل Reality را ارائه می‌دهد، به‌علاوهٔ XHTTP و Hysteria2 روی آدرس IP سرور. دامنه شما دو چیز را تغییر می‌دهد:

- **XHTTP** به دامنه شما منتقل می‌شود و **WSS** هم همان‌جا اضافه می‌شود، با یک certificate Let's Encrypt که Meridian صادر و تجدید می‌کند (acme.sh)
- هنگامی که دامنه از طریق Cloudflare proxied می‌شود، هر دو مسیر از طریق CDN Cloudflare می‌رود — بنابراین حتی اگر IP سرور شما مسدود شود کار می‌کنند

سرویس کنترل و صفحات اتصال روی certificate IP سرور باقی می‌مانند؛ دامنه تنها مسیرهای proxy را حمل می‌کند.

Hysteria2 روی UDP/443 هم به certificate دامنه می‌رود (ببینید [Hysteria2 و Cloudflare](#hysteria2-و-cloudflare))؛ `--no-hysteria2` آن را خاموش می‌کند.

## راه‌اندازی Cloudflare

**این ترتیب را دنبال کنید** تا مشکلات certificate جلوگیری شود:

1. دامنه خود را در Cloudflare اضافه کنید و یک **رکورد A** ایجاد کنید که به IP سرور شما اشاره کند
2. آیکن ابر را **خاکستری** نگاه دارید ("DNS only")
3. `meridian deploy 198.51.100.10 --domain vpn.example.com` را اجرا کنید — Meridian certificate را می‌گیرد
4. رکورد را به **ابر نارنجی** تغییر دهید (Proxied)
5. SSL/TLS را **Full (Strict)** تنظیم کنید و **WebSockets** را روشن کنید (تنظیمات شبکه)

Deploy این مراحل را دوباره زمانی که تمام می‌شود چاپ می‌کند.

> **مهم:** certificate با یک HTTP challenge روی پورت 80 صادر می‌شود. "Always Use HTTPS" Cloudflare این challenge را خراب می‌کند — آن را خاموش کنید یا `/.well-known/acme-challenge/*` را معاف کنید.

## لینک‌های اتصال

فهرست subscription و صفحه اتصال هر کلاینت هر مسیر را فهرست می‌کند:

| مسیر | نحوهٔ عبور | چه زمانی کمک می‌کند |
|------|-------|---------------|
| Reality | مستقیم به IP سرور | مسیر اصلی — سریع‌ترین |
| XHTTP | دامنهٔ شما (از طریق Cloudflare در حالت Proxied) | زمانی که Reality مسدود یا کند شده باشد |
| WSS | دامنهٔ شما (از طریق Cloudflare در حالت Proxied) | زمانی که IP سرور مسدود شده باشد |
| Hysteria2 | IP سرور شما روی UDP/443 با گواهی دامنه | شبکه‌های دارای اتلاف بسته یا تأخیر زیاد، یا وقتی همهٔ مسیرهای TCP مسدود باشند |

برنامه‌هایی که اشتراک Xray JSON، Mihomo یا sing-box را وارد می‌کنند، وقتی یک مسیر از کار بیفتد به‌طور خودکار به مسیر دیگر می‌روند. برنامه‌های دیگر هر مسیر را به عنوان یک ورودی جداگانه نشان می‌دهند.

## Hysteria2 و Cloudflare

Hysteria2 روی UDP IP سرور شما dial می‌کند و تنها از دامنه برای certificate TLS استفاده می‌کند، بنابراین وقتی رکورد از طریق Cloudflare proxied می‌شود کار می‌کند (که نمی‌تواند آن را حمل کند). obfuscation salamander بسته‌های آن را تصادفی نشان می‌دهد، نه شبیه QUIC. جایی که UDP مسدود است، برنامه‌ها به مسیرهای TCP که پیش از آن فهرست شده‌اند برمی‌گردند.

## اضافه کردن دامنه بعداً

دستور deploy خود را دوباره با افزودن `--domain` اجرا کنید. لینک‌های Reality موجود همچنان کار می‌کنند. برای حذف دامنه در آینده، بدون `--domain` بازاستقرار کنید: مسیر WSS حذف می‌شود، XHTTP و Hysteria2 به گواهی IP سرور برمی‌گردند و اشتراک‌ها به‌روز می‌شوند.
