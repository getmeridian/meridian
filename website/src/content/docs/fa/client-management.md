## افزودن کلاینت

```
meridian client add alice
```

این به "alice" کلید خود و دو چیز را برای اشتراک می‌دهد:

- **لینک صفحه اتصال** با کد QR — ساده‌ترین راه برای ارسال
- **URL اشتراک** برای درج مستقیم در برنامه Xray/V2Ray

چندین نفر را یک‌زمان اضافه کنید:

```
meridian client add alice bob charlie
```

کلاینت‌ها به کل فلیت شما تعلق دارند، نه یک سرور. هر exit و relay شما در اشتراک آن‌ها نمایش داده می‌شود.

### آنچه گیرنده می‌بیند

صفحه اتصال از اشتراک واقعی فرد ایجاد می‌شود، بنابراین دقیقاً مسیرهایی که برنامه‌های آن‌ها دریافت می‌کنند را نشان می‌دهد: exit‌های مستقیم، relay‌ها و Hysteria2 وقتی فعال باشد. شامل:

- دستورالعمل‌های گام‌به‌گام برای نصب برنامه (v2RayTun، v2rayNG، Hiddify یا v2rayN)
- کد QR برای هر مسیر اتصال
- پیوندهای "باز در برنامه" یک‌کلیک

لینک را از طریق هر پیام‌رسانی ارسال کنید. گیرنده آن را باز می‌کند، برنامه را نصب می‌کند، کد QR را اسکن می‌کند و متصل می‌شود.

## نمایش جزئیات اتصال

برای اشتراک دوباره لینک‌های کلاینت:

```
meridian client show alice
```

این صفحه اتصال و URL اشتراک را چاپ می‌کند، به‌علاوه وضعیت، ترافیق و زمان آخرین اتصال. اگر صفحه گم باشد (مثلاً بارگذاری ناموفق بود)، آن را دوباره منتشر کنید:

```
meridian client show alice --repair-page
```

## فهرست کلاینت‌ها

```
meridian client list
```

هر کلاینت را با وضعیت، ترافیق، زمان ایجاد و آخرین اتصال نمایش می‌دهد.

## معلق کردن و از سرکشی درآوردن کلاینت

```
meridian client disable alice
meridian client enable alice
```

`disable` کلاینت را فوراً قطع می‌کند؛ `enable` آن‌ها را با همان لینک‌ها دوباره فعال می‌کند.

معلق کردن موقتی است: بعدی اعمال تمام کلاینت اعلام‌شده را دوباره روشن می‌کند. اعمال برای `meridian apply`، بازاستقرار و هنگام افزودن کلاینت، نود یا relay اجرا می‌شود. اگر لزم باشد دوباره معلق کنید.

## حذف کلاینت

حذف دائمی هنوز دسترس نیست — `meridian client remove` رد می‌کند و توضیح می‌دهد. اکنون از `meridian client disable` برای لغو دسترسی استفاده کنید. کاربر را در پنل Remnawave حذف نکنید: Meridian آن را در بعدی اعمال دوباره ایجاد می‌کند.

## لینک‌های اشتراک

URL‌های اشتراک مثل `https://198.51.100.10/<page-path>/sub/<id>` هستند. آن‌ها زیر مسیر صفحه اتصال زندگی می‌کنند؛ پنل مدیریت Remnawave روی مسیر مخفی جداگانه است که لینک‌های اشتراکی هرگز آن را فاش نمی‌کنند.

برنامه‌ها اشتراک را خود تازه می‌کنند، بنابراین هنگام افزودن exit یا relay، کلاینت‌ها بدون لینک جدید آن را به‌دست می‌آورند.

## محل زندگی اطلاعات کلاینت

حساب‌های کلاینت (کلیدها، وضعیت، ترافیق) در پایگاه داده پنل Remnawave روی سرور control-plane زندگی می‌کنند. فهرست کلاینت‌های که Meridian مدیریت می‌کند بخش توپولوژی شما در `~/.meridian/cluster.yml` است. فرمان‌های کلاینت از API پنل استفاده می‌کنند و SSH نیاز نیست؛ منتشر کردن صفحه اتصال از SSH به سرور control-plane استفاده می‌کند.

## پنل وب

پنل مدیریت [Remnawave](https://remna.st/) ترافیق، کاربران و نودها را در مرورگر نشان می‌دهد. URL و ورود مدیریت در بخش `panel` فایل `~/.meridian/cluster.yml` است و استقرار URL را به‌عنوان "Remnawave panel (advanced)" چاپ می‌کند.

برای دیدن استفاده کنید؛ برای تغییر Meridian را استفاده کنید. Meridian کاربران، میزبان‌ها و template‌های که مدیریت می‌کند را در بعدی اعمال بازگردانده، و `meridian plan` ابتدا هر تفاوتی را نشان می‌دهد.
