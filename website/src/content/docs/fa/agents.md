Meridian طوری ساخته شده که علاوه بر انسان‌ها، عامل‌های هوش مصنوعی هم بتوانند آن را اداره کنند. یک عامل با همان دستورهایی که شما به کار می‌برید، می‌تواند سرور استقرار دهد، کاربر اضافه کند، بررسی‌های سلامت را بخواند و دلیل خطاها را توضیح دهد.

## عامل خود را با Meridian آشنا کنید

از عامل بخواهید پیش از هر کار دیگری این دستور را اجرا کند:

```bash
meridian help agents
```

این دستور یک راهنمای کوتاه Markdown برای عامل‌ها چاپ می‌کند: Meridian چه کاری انجام می‌دهد، fleet چگونه از اجزا تشکیل می‌شود، وضعیت آن کجا نگهداری می‌شود، قواعد استفادهٔ ایمن از CLI، کدهای خروج و کارهای رایج. همین راهنما در [getmeridian.org/agents.md](https://getmeridian.org/agents.md) هم موجود است.

برای ماندگار کردن این کار، یک خط به دستورالعمل‌های عامل پروژه‌تان (`AGENTS.md`، `CLAUDE.md` یا معادل ابزارتان) اضافه کنید:

```markdown
سرورهای پروکسی ما با Meridian مدیریت می‌شوند. پیش از استفاده از آن، `meridian help agents` را اجرا کنید.
```

## آنچه CLI در اختیار عامل‌ها می‌گذارد

- **بدون پرسش.** دستورهایی که چیزی را تغییر می‌دهند `--yes` را می‌پذیرند. ویزارد `setup` به ترمینال نیاز دارد، پس عامل‌ها از `deploy`، `node add`، `relay add` و `client add` یا `setup --intent FILE --yes` استفاده می‌کنند.
- **envelope‌های JSON.** دستورهای دارای `--json` یک envelope با نام `meridian.output/v1` را روی stdout چاپ می‌کنند، حتی برای خطاها. پیشرفت و هشدارها روی stderr می‌روند.
- **قراردادها.** `meridian api commands` همهٔ دستورها را با یک قرارداد ماشین‌خوان فهرست می‌کند و `meridian api schema NAME` JSON Schema آن را چاپ می‌کند.
- **کدهای خروج معنادار.** `0` یعنی موفقیت، `2` خطای کاربر، `3` نبود شواهد (SSH، سرویس کنترل یا وضعیت محلی) و `4` بررسی کامل‌شده‌ای که مشکل پیدا کرده است. برای جزئیات هر دستور به [مرجع CLI](/fa/cli-reference/) مراجعه کنید.
- **اول بازبینی، بعد تغییر.** `meridian plan` نشان می‌دهد چه چیزی تغییر می‌کند و `meridian apply --yes` دقیقاً همان را اعمال می‌کند.

## آنچه مستندات در اختیار عامل‌ها می‌گذارد

- **هر صفحه به‌صورت Markdown.** به نشانی هر صفحه `.md` اضافه کنید، مثلاً [/fa/relay.md](/fa/relay.md). هر صفحه در `<head>` خود نیز به نسخهٔ Markdown خودش پیوند می‌دهد.
- **دکمه‌های «کپی صفحه» و «باز کردن در».** زیر عنوان هر صفحه می‌توانید آن را به‌صورت Markdown کپی کنید یا در ChatGPT یا Claude باز کنید.
- **llms.txt.** [/llms.txt](/llms.txt) فهرست مستندات برای مدل‌های زبانی است و [/llms-full.txt](/llms-full.txt) همهٔ آن‌ها را در یک فایل دارد.

## رمزها و لینک‌ها را از گفتگو دور نگه دارید

صفحه‌های اتصال و URLهای اشتراک به هر کسی که آن‌ها را دارد، دسترسی به سرورهایتان می‌دهند. راهنمای عامل‌ها به آن‌ها می‌گوید هر لینک را فقط به کسی بدهند که به او تعلق دارد و لینک راه‌اندازی کنسول را چاپ نکنند، مگر اینکه خودتان بخواهید. لینک‌ها را در گفتگویی که با دیگران به اشتراک گذاشته‌اید نچسبانید. `meridian doctor` گزارشی با اطلاعات حساسِ حذف‌شده تولید می‌کند که اشتراک‌گذاری‌اش امن است.
