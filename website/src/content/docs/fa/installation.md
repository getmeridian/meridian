## نصب سریع

```
curl -sSf https://getmeridian.org/install.sh | bash
```

این اسکریپت:
1. اگر [uv](https://docs.astral.sh/uv/) موجود نباشد آن را نصب می‌کند و از pipx یا pip به‌عنوان راه جایگزین استفاده می‌کند
2. `meridian-vpn` را از PyPI نصب می‌کند
3. در صورت نیاز پوشه ابزار را به PATH پوسته اضافه می‌کند
4. فقط وقتی sudo بدون گذرواژه در دسترس باشد `/usr/local/bin/meridian` را ایجاد می‌کند

## نصب دستی

با uv (توصیه شده):
```
uv tool install meridian-vpn
```

با pipx:
```
pipx install meridian-vpn
```

## به‌روزرسانی

```
meridian update
```

Meridian پیش از دستورهای تعاملی PyPI را دوره‌ای بررسی می‌کند و هیچ به‌روزرسانی را خودکار نصب نمی‌کند. `meridian update` نصب‌های پیدا‌شده uv، pipx و pip را به‌ترتیب امتحان و بعد از هرکدام نسخه همان دستور فعال `meridian` را تأیید می‌کند؛ به‌روزرسانی یک environment غیرفعال موفقیت محسوب نمی‌شود. کد `0` یعنی نسخه جدید است یا ارتقا تأیید شده و `3` یعنی کشف نسخه، نصب یا تأیید شکست خورده است. برای automation از `MERIDIAN_DISABLE_UPDATE_CHECK=1` استفاده کنید.

## نیازمندی‌ها

- **Python 3.11+** (حداقل نسخه پروژه؛ uv می‌تواند آن را خودکار نصب و مدیریت کند)
- دستورهایی که میزبان را تغییر یا عیب‌یابی می‌کنند به **دسترسی SSH** نیاز دارند. `test` و `probe` از دستگاه کلاینت و بدون SSH اجرا می‌شوند؛ Studio می‌تواند یک بار با گذرواژه کلید نصب کند

اولین `meridian test` کامل، Xray ثابت را در deadline جداگانه 120 ثانیه از GitHub دانلود و checksum منتشرشده را تأیید می‌کند. آزمون‌های بعدی از cache کامل محلی استفاده می‌کنند؛ `--timeout` بررسی‌های شبکه را کنترل می‌کند، نه این bootstrap اولیه.
کدهای QR ترمینال با بستهٔ Python داخلی `segno` ساخته می‌شوند و به وابستگی سیستمی نیاز ندارند.
