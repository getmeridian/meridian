运行 Meridian 服务器的人给你发来了一个链接。本页是写给你的：你不需要命令行，也不需要任何服务器知识。


账户可以设为首次使用后若干天有效。打开此页面或刷新订阅不会开始计时；节点代理首次报告您的流量时才会开始。此前账户仍可连接。激活后，账户面板会按浏览器时区显示真实到期时间，并附 UTC 时间。如果配置了自动续期，还会显示下次续期、下次流量重置及剩余续期次数。

## 打开链接

在你想要连接的设备上打开链接。它会带你到**连接页面**，页面会识别你的设备，并引导你完成三个步骤：

1. **安装应用。** 页面会推荐适合你平台的应用，并提供下载链接。
2. **添加连接。** 为你安装的应用点击**添加到 …**。应用会打开，你的连接已经在里面了。
3. **连接。** 在应用中开启连接；如果设备请求 VPN 权限，请允许。

要用电脑设置手机，请在电脑上打开链接，然后用手机的相机或应用中的扫码功能扫描步骤旁边的二维码。

请不要把链接告诉别人。它是你的个人访问凭证，任何拿到它的人都可以以你的身份连接。

所有者启用设备上限后，您的账户会显示已用 / 允许的设备名额。名额用满后，新设备刷新订阅时会收到上限提示。不报告设备标识的应用不计数。页面只显示计数，不会将其保存在浏览器中。

## 页面语言

页面先使用您保存的语言选择，然后使用账户语言，再使用管理者的默认值。自动模式下，连接页和帮助页跟随浏览器语言，必要时回退到英语。

您随时可以通过页面上的语言按钮切换语言。选择会保存在此浏览器中，也用于帮助页。波斯语页面采用从右到左的布局。

## 开启 VPN（TUN）模式

大多数应用以代理或 VPN 两种方式之一运行。如果只以代理模式运行，有些应用会绕过连接，浏览器中的网站有时可能获知你的真实 IP 地址（WebRTC 泄漏）。请在应用中开启 **VPN** 或 **TUN** 模式，让所有流量都经过连接。你可以用任意泄漏检测网站确认：显示的地址应与你平时的地址不同。

## 应用中的条目

你的应用会列出多个条目，按国家和方式命名，例如“🇩🇪 DE · Reality · Chrome”或“🇩🇪 DE · XHTTP · Chrome”。它们是通往同一服务的不同路线；在某个网络上被封锁的路线，换另一条也许就能用。标有“via relay”的条目会先经过一台额外的服务器。如果你的应用提供自动条目，请使用它；它会自行切换到可用的路线。

## 无法使用时

应用里的延迟显示红色或“n/a”，并不代表连接坏了：应用用自己的方式测试，这种测试可能失败，而连接其实可用。请先连接，再打开一个网站。如果网站确实打不开，请按顺序尝试下面的做法。同样的提示也在你的连接页面的**无法连接？**下。

1. **刷新订阅。** 应用会自动更新订阅；如需立即更新，请在应用中打开订阅（或配置）列表并点击**更新**。这样可以获取新的服务器和路线。如果应用有“启动时更新订阅”之类的设置，请开启。
2. **换一个条目。** 选择方式不同的条目，或标有“via relay”的条目。
3. **检查设备的时钟。** 时钟相差超过一分钟可能导致连接失败；请开启自动设置日期和时间。
4. **运行连接检查。** 请先关闭 VPN 应用，让检查看到你真实的网络环境。打开你的连接页面，展开**无法连接？**和**检查我的连接**，点击**开始检查**。然后点击**复制报告**，并把它发给给你链接的人；报告中不含任何链接或密钥。
5. **寻求帮助。** 如果连接页面本身也打不开，可能是你的网络封锁了服务器。请告诉运行它的人；[从封锁中恢复](/zh/recovery/)是他们的职责，你的应用会在下次刷新时获取新的路线。

## 联系所有者

连接页面的 **无法连接？** 区域可能显示所有者的说明及 **联系所有者** 按钮。访问已到期、流量额度耗尽，或连接检查仍未解决问题时，可以使用它。点击后会打开所有者选定的网站、通讯应用或邮件应用。

应用的支持按钮可能打开同一联系链接。如果它打开的是 Meridian 支持页面，请按照所有者的说明操作，或选择 **打开连接页面**。这些说明由提供并管理你连接的人填写。

## 管理者消息

连接页面可能显示管理者的通知，例如维护时间。部分应用会在刷新订阅后显示同一条通知，其中的账户值会按您的信息填写。通知到期后会消失；页面从同一个服务获取通知，不发送外部请求。

## 应用中的状态消息

如果访问被停用、已到期或流量额度已用完，应用列表中的提示会解释原因，并请您联系管理者。这些提示使用账户语言或管理者的默认值；自动模式下保持英语。页面上的语言按钮会将您的选择保存在此浏览器中。这些说明条目无法连接；请联系管理者恢复访问。

## 应用中的更新提示

如果你的应用太旧，无法使用服务提供的全部功能，或已停止维护，它的列表末尾可能多出一个条目，请你更新应用，或从 NekoRay 改用 Throne。这只根据应用在获取订阅时报出的名称和版本判断，不保存任何内容。该条目不能连接，你原有的条目不受影响。请在连接页面的应用列表中安装新版，然后刷新订阅。

## 应用列表不一样时

应用收到的是各自支持的格式，因此列表可能不同。如果某种连接方式没有显示，请告诉管理者您使用的应用和版本。对方可预览格式及条目被省略的原因，无需分享您的连接密钥。设置更改后，请刷新订阅。

## 已授权连接

页面及所有应用订阅仅列出运营者授权的连接。多个配置可合并权限，但配置名称和成员关系属于运营者的私有数据。访问权限变化后请刷新订阅；页面使用当前授权列表。节点应用变更后，失去授权的连接也无法继续认证。已开始的传输可能继续到结束，或直到运营者执行共享节点断开。订阅 URL 和连接密钥保持不变。


## 预览与解释路由

`meridian client preview person --suffix singbox --json` 与面板订阅预览显示有效策略、选择来源、各格式的有序规则与 DNS，以及省略的功能和原因。可选目的地字段解释当前格式。Xray 预览区分缺少指定出口的单连接配置与指纹配置。规则编号在各格式之间一致：局域网规则最先，其次为自定义规则，最后为内置模式的其余规则。同一编号可能编译为客户端文件中的多条规则。

```bash
meridian fleet routing set work --dry-run --json
meridian fleet routing explain chat.example.test:443 --person person --format singbox --json
meridian fleet routing explain 198.51.100.10 --format xray-json --port 443 --network tcp --protocol other --json
```

`fleet routing explain` 读取服务当前已应用的设置及可选个人私有覆盖，返回首次匹配的规则与动作，例如“此目的地通过出口 west，因为规则 2 匹配”。省略 `--person` 可解释服务器默认策略。`--format` 选择 Xray JSON、Mihomo/Clash、Stash、sing-box 或 Base64。默认假设 TCP 和普通流量；`--protocol bittorrent` 提供模拟的协议检测结果。不发送 DNS、网络或可达性查询。更早的规则需要未知端口或缓存中缺失的固定版本地理数据时，结果显示未知。Xray 使用 `IPIfNonMatch` 先检查域名；最终 TCP/UDP 规则将未匹配的域名送入隧道，路由选择无需本地 DNS 查询。IP 规则匹配以 IP 地址连接的目的地。应用选择与服务器可达性可能改变自动组实际使用的连接。

| 格式 / 应用 | 目的地规则 | DNS | fake-IP | 指定出口 | BitTorrent |
| --- | --- | --- | --- | --- | --- |
| Xray JSON 应用 | 全部八类匹配 | DoH、普通 DNS | 省略 | 仅限当前配置 | 尽力检测 |
| Mihomo / Clash Meta | 全部八类 | DoH、DoT、普通 DNS | 支持 | 仅主连接 | 省略 |
| Stash | 全部八类 | DoH、DoT、普通 DNS | 原生模式，省略自定义 fake-IP | 仅主连接 | 省略 |
| sing-box / Hiddify | 内联域名、CIDR、端口、TCP/UDP、私有 IP | DoH、DoT、普通 DNS | 支持 | 仅受支持连接 | 省略 |
| Base64 链接应用 | 无规则 | 无设置 | 不支持 | 无基于规则的选择 | 不支持 |

服务仅从缓存中读取通过 Meridian 固定哈希验证的 Xray 压缩包，不会因解释路由而开始下载。客户端不会收到远程规则集。Xray 将已配置的公共 DNS 请求通过自动组发送，同时保留局域网 DNS 直连；其他客户端使用可表示的 DNS 设置。不支持的传输不会转换为普通 DNS。原有内置模式的字节内容和默认配置的黄金语料响应保持不变。

`POST /api/delivery-policies/explain` 接受 `destination`、可选 `person`、`format`、`port`、`network`、`protocol`。需要 `delivery.explain`；指定用户时还需要 `people.read` 和 `people.private`。订阅预览中的策略详情或目的地解释需要私有权限，较低权限仅返回原有元数据。连接页面的 `/info` 可包含 `user.deliveryCapabilities`：格式名称、支持标志与省略代码，不含策略名称、个人覆盖、成员关系、目的地或连接详情。页面仅在内存中保留这些新鲜数据。
