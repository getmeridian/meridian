Meridian 正确配置服务器，但无法改变服务器所在位置。在用户网络阻止的地址上完美的 Reality 设置仍然无法连接。本页面帮助您在投入大量资金前选择和测试托管。

您租用两种类型的服务器，它们有不同的需求：

- **出口**：承载所有到开放互联网的流量。应位于被审查的国家外。
- **中继**：出口前面的小型 TCP 转发器，请参见[中继节点](/docs/zh/relay/)。它需要一个用户可以到达的干净地址，仅此而已。

## 要查看什么

**地址和网络声誉。** 审查者可以阻止或限制单个 IP、一个子网或来自一个托管网络的所有内容。大型、知名的托管网络最有可能被大规模阻止，俄罗斯的部署者报告说块有时会击倒从未运行过代理的邻近客户。较小的主机在不太明显的位置通常持续更久，但是每个人都推荐的主机停止模糊。您无法提前知道，所以要测试（见下）。移动网络比家庭连接更严格：相同的 IP 在家庭线路上可能有效，在每个移动运营商上都可能失败。

**位置和延迟。** 选择与用户网络有良好路由、延迟足够低的国家。从用户自己的网络测试，而不是从国外的笔记本电脑。在部署前使用 `meridian check` 查看服务器如何到达其伪装目标。

**带宽和公平使用。** "无限制"通常配有公平使用条款，通常每月数 TB，有些主机对便宜或免费计划采用低速。阅读条款并检查您真正获得的端口速度。中继承载用户通过它发送的流量，所以大小应相同。

**IPv4。** 计划使用公开 IPv4 地址，并期望在某些主机上为其支付额外费用。一些工具，如 `meridian scan`，仅在 IPv4 上工作。

**付款和账户。** 选择您对其付款方式和注册要求满意的提供商，如果隐私重要，请将账户详情与您的个人账户分开。按小时计费比小折扣更值得，因为它让您便宜地测试。

**干净的操作系统和 root 访问权限。** Meridian 需要带 SSH 密钥登录的新鲜 Debian 或 Ubuntu 服务器。避免预装控制面板或您无法控制的防火墙的主机。

## 在支付大量费用前测试 IP

1. 租用最小计划（**按小时计费**），或有退款窗口的。
2. 为预飞检查运行 `meridian check IP`：伪装目标、端口 443、外部可达性、操作系统、磁盘和时钟。
3. 部署，然后**从用户所在网络内部**运行 `meridian test` 和 `meridian test --probe`，在家庭连接和移动连接上都运行。`--probe` 也报告服务器 IP 或伪装 SNI 是否看起来被阻止。来自被审查网络外的结果证明的很少。
4. 让它运行几天并再次测试。有些地址最初有效，后来被限制。
5. 如果失败，删除服务器并租用另一个地址，然后再次测试。按小时计费使这变得便宜。

当服务器在原来有效之后停止工作时，请参见 [IP 阻止恢复](/docs/zh/recovery/)。

## 不要在何处放置出口

俄罗斯内的出口很脆弱。主机在当地规则下运营，可以看到并作用于您的服务器，来自俄罗斯主机的报告描述了代理服务器的身份验证和删除。保持出口在国外。仅将国内服务器用作中继，其转发加密字节并运行任何代理软件。

## 国内中继承载风险

国内主机上的中继在外国 IP 被阻止时有帮助，但租用它的人承担风险。它以他们的名义租用，受当地法律约束，主机可能要求身份检查或结束服务。中继仅转发在客户端和出口之间端到端加密的 TCP，所以主机看到对您出口地址的连接及其数量，而不是内容。关于用户在线做什么的滥用投诉转到出口的提供商。这不是法律建议：在为他人租用中继前理解您的当地规则和主机的条款。

## 不要依赖一条路径

块变化很快，所以计划它们：

- 将 Reality 部署为主路径，通过 Cloudflare 添加[域名模式](/docs/zh/domain-mode/)用于 XHTTP 和 WSS，以及 QUIC 对您用户有效的地方添加 `--hysteria2`。
- 在不同的提供商和网络上保持第二个出口（`meridian node add`），所以一个被阻止的地址范围不会导致一切崩溃。
- 为阻止您出口地址的网络添加中继。

每个客户的订阅列出所有这些，使用 Xray JSON 或 Mihomo 订阅的应用会自动切换路径。

## 伪装目标

主机的网络也形成了最佳伪装目标。选择与您的服务器相邻看起来自然的网络上具有 TLS 1.3 的流行网站：`meridian scan` 在服务器自己的邻域中查找候选者。不要选择 `apple.com` 或 `icloud.com`（它们的网络与托管提供商不匹配），也不要选择 `www.microsoft.com`：其证书链对 REALITY 来说太大了，所以部署收敛但没有流量通过。请参见[选择伪装目标](/docs/zh/deploy/#choosing-a-camouflage-target)。
