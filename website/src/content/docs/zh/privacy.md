---
title: 隐私
description: 选择设备限制和用量历史保存哪些信息，了解控制服务器被夺取后会暴露什么。
---

Meridian 默认**关闭设备限制**并**关闭用量历史**。需要更多记录时，由你主动启用。任何级别都不会保存客户端 IP 地址、连接日志或请求路径。

控制服务已经保存人员账户及连接凭据、累计流量总量和最后活跃时间。夺取服务器的人可以读取这些状态。隐私设置决定在此基础上增加哪些设备详情和每日记录。

## 设备限制

| 级别 | Meridian 保存的信息 | 你看到的信息 |
| --- | --- | --- |
| `off`（默认） | 无设备记录，不追踪或限制设备 | 无设备计数 |
| `private` | 使用服务器组内部专用密钥对设备 ID 计算 HMAC-SHA256 指纹，不保存系统、型号或应用 | 设备数量及上限 |
| `full` | 设备 ID、平台、系统版本、型号、user agent、首次和最近获取订阅的时间 | 每个人的设备列表 |

**private 的隐私说明：**

> 每个人的设备通过不可读的指纹计数。Meridian 不保存设备名称、系统或应用。夺取控制服务器的人只能检查他们已经掌握的某台设备是否曾被使用。

**full 的隐私说明：**

> Meridian 保存每台设备的 ID、系统、型号、应用以及上次获取订阅的时间。夺取控制服务器的人会知道每个人使用哪些设备。地址永远不会被保存。

默认上限是 **3 台设备**，可设为 **1–100 台**。当个人未设置自己的上限时使用此默认值。参见[客户端管理](/zh/client-management/)。

启用可计数的设备上限后，`/info` 和连接页面只显示已用与允许的名额数（`user.deviceSlots.used` 和 `allowed`）。持有个人链接的任何人都能看到这些计数，包括名额已满或上限被降低的情况。不会包含设备标识、名称、系统、型号或设备活动时间。页面只在内存中保留计数；关闭上限时不显示。名额用满后，新设备刷新订阅时会收到上限提示；已登记设备仍可使用。不发送受支持设备标识的应用不计数。

## 用量历史

| 级别 | Meridian 保存的信息 |
| --- | --- |
| `off`（默认） | 累计总量和最后活跃时间，无每日历史 |
| `daily` | 每个人每天的上传和下载字节总量，以及每台服务器每天的总字节数，按 UTC 天统计 |

每日历史默认保留 **90 天**，可选 **7–730 天**，含今天。每 30 秒清理较早记录；缩短保留时间会立即清理。

> Meridian 保留每个人和每台服务器每天的用量，保存 N 天。夺取控制服务器的人会知道每个人何时活跃。

流量计入控制服务收到新计数增长的 UTC 日期。延迟报告计入收到报告的日期。重试只计一次。启用历史之前的用量不会补算；空白日期表示没有记录的流量。重置个人流量额度会保留其每日历史。

网页面板提供个人图表及可选择服务器的服务器图表。CLI 提供紧凑表格：

```bash
meridian client usage alice --days 30
meridian client show alice                 # 历史开启时附最近 7 天
meridian fleet usage --days 7
```

查询范围受已保存的保留时间限制。历史关闭时，用量 API 返回 `409 history_off`。

## 更改设置

这些选项属于控制服务。应用服务器组配置文件不会改变它们。

```bash
meridian privacy                          # 等同于 privacy show
meridian privacy show --json
meridian privacy set --devices private --device-limit 3
meridian privacy set --history daily --history-days 90
meridian privacy set --devices off --history off --yes --json
```

只更改你传入的选项。提高级别会在确认前显示隐私说明；`--yes` 跳过询问。JSON 模式的变更需要 `--yes`。重复相同设置不会产生变更。

在网页面板打开**设置 → 隐私**。每个选项均显示隐私说明。保存前阅读确认内容；所有者需要最近的密码确认，如启用了登录验证码，也需要验证码。读取 API 需要 `read`，写入需要 `admin`。

每次设置变更都会记录操作人（令牌名称、`owner` 或 `root`）、时间及完整的前后值。网页面板和 CLI 显示最近 50 次变更。

## 降低级别

- `full` → `private` 将保存的 ID 转为带密钥的指纹，并删除系统、型号和应用信息。
- 设备 → `off` 删除所有设备记录。
- `daily` → `off` 删除所有人员和服务器的每日记录。累计总量及最后活跃时间保留。
- 缩短保留时间会删除新上限之外的记录。

设置、删除及变更记录一起提交。响应说明删除或转换了多少条记录。删除人员也会删除其每日记录；服务器汇总历史保留至保留期结束。

指纹无法还原为设备 ID。从 `private` 切换到 `full` 会清空私密记录；设备在下次获取订阅时重新注册。

## 快照与恢复

隐私设置和变更日志包含在加密快照中。设备记录和每日历史只有在对应级别开启时才包含在快照中。

服务器组的指纹密钥是服务密钥，**永远不会包含在快照中**。恢复后，**private 设备记录会被清空**；设备在下次获取订阅时重新注册。full 设备记录和已启用的每日历史会在恢复后保留。

降低级别影响当前状态和未来快照。已保存的快照仍包含保存时对应级别的记录；请用备份密钥保护这些副本。参见[恢复](/zh/recovery/)。
