## Проблема

Meridian включает **блокировку по географическому принципу на стороне сервера** по умолчанию: выход отбрасывает трафик к российским доменам (`geosite:category-ru`) и российские диапазоны IP (`geoip:ru`). Это держит ваш IP VPS вне логов российских сервисов, где его можно обнаружить и заблокировать.

Проблема: российские веб-сайты не открываются, пока VPN включен. Пользователи должны отключиться для достижения Yandex, VK, Gosuslugi и других отечественных сервисов.

## Решение: раздельная маршрутизация на устройстве

Раздельная маршрутизация отправляет российский трафик **прямо** с устройства и всё остальное через VPN:

```
Российские сайты → Устройство → Прямой → Internet (местный ISP)
Всё остальное  → Устройство → Прокси → VPS → Internet
```

Вы получаете оба:
- **Защита VPS** — блок на стороне сервера остаётся как подстраховка
- **Работающие российские сайты** — устройство отправляет их прямо, никогда через VPN

## Как это работает в Meridian

Meridian поставляет раздельную маршрутизацию в своих подписках **Xray JSON** и **Mihomo**, поэтому большинство приложений не требуют настройки. Каждая подписка отправляет эти направления прямо:

- адреса локальной сети (`geosite:private`, `geoip:private`)
- домены `.ru`, `.su` и `.рф`, плюс `geosite:category-ru`
- российские диапазоны IP (`geoip:ru`)

Она также отказывает в QUIC (UDP 443) всему остальному, поэтому приложения возвращаются к TCP, где прокси маршрутизирует их по имени.

Приложения, импортирующие простой список ссылок (Base64), не получают правила маршрутизации. В этих приложениях добавьте **direct** правила для `geosite:category-ru` и `geoip:ru` в параметры маршрутизации, или переключитесь на приложение, которое импортирует подписки Xray JSON или Mihomo. Пользователи Hiddify вместо этого могут установить регион на **Russia**.

### Почему не редактировать шаблон в панели?

Meridian управляет своим собственным JSON Xray и Mihomo шаблонами подписки в Remnawave. Они несут автоматический возврат между вашими выходами и промежуточными серверами, и маршрутизацию выше. Meridian восстанавливает их при каждом применении (включая переразворачивания и `client add`, `node add`, `relay add`), поэтому правила добавленные там в панели не продержатся.

## Как слои работают вместе

| Слой | Что он делает | Защищает от |
|-------|-------------|-----------------|
| **Блокировка по географическому принципу на стороне сервера** | Отбрасывает трафик, направленный в Россию, на выходе | IP VPS, показывающийся в логах российских сервисов |
| **Раздельная маршрутизация на устройстве** | Отправляет российский трафик прямо | Сломанные российские сайты, ненужная нагрузка на VPN |

Российский трафик никогда не достигает сервер. Если устройство не имеет правил (импорт Base64, старое приложение), сервер всё ещё блокирует российские направления, поэтому IP VPS остаётся защищённым.

Если ваши пользователи нуждаются в российских сайтах через VPN вместо этого, разверните с `--no-geo-block`.

## Соображения DNS

В подписках Xray JSON имена, которые не соответствуют никакому правилу, разрешаются через VPN, поэтому иностранные поиски не утекают на локальный ISP. Подписки Mihomo соответствуют российским диапазонам IP только для соединений, сделанных по IP, и никогда не разрешают другие имена локально. Если ваше приложение имеет отдельный параметр DNS, включите защиту от утечек DNS для трафика через VPN.
