## Быстрая установка

```
curl -sSf https://getmeridian.org/install.sh | bash
```

Этот скрипт:
1. Устанавливает [uv](https://docs.astral.sh/uv), если его нет; резервные варианты — pipx и pip
2. Устанавливает `meridian-vpn` с PyPI
3. При необходимости добавляет каталог инструмента в PATH оболочки
4. Создаёт `/usr/local/bin/meridian` только при доступном беспарольном sudo

## Ручная установка

С uv (рекомендуется):
```
uv tool install meridian-vpn
```

С pipx:
```
pipx install meridian-vpn
```

## Обновить

```
meridian update
```

Meridian периодически проверяет PyPI перед интерактивными командами и сообщает о новой версии. Обновления никогда не устанавливаются автоматически. `meridian update` последовательно пробует обнаруженные uv, pipx и pip установки и после каждой проверяет версию именно активной команды `meridian`; обновление не считается успешным, если обновился неиспользуемый environment. Код `0` означает «уже актуально» или подтверждённое обновление, `3` — сбой поиска версии/установки/проверки. Для автоматизации фоновую проверку можно отключить через `MERIDIAN_DISABLE_UPDATE_CHECK=1`.

## Требования

- **Python 3.11+** (минимальная версия проекта; uv может установить и управлять ею автоматически)
- **SSH-доступ** к целевому серверу для команд, изменяющих или диагностирующих хост. `test` и `probe` работают с клиентской машины без SSH; Studio может однократно установить ключ с помощью пароля

Первый полный `meridian test` загружает закреплённый Xray и проверяет опубликованный checksum с GitHub в отдельном deadline 120 секунд. Последующие тесты используют полный локальный cache; `--timeout` управляет сетевыми проверками, а не этой первоначальной загрузкой.

QR-коды в терминале создаёт включённый в пакет Python-модуль `segno`; системные зависимости не требуются.

## Проверить установку

```
meridian --version
```
