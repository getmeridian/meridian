Meridian рассчитан на работу не только с людьми, но и с ИИ-агентами. Агент может развёртывать серверы, добавлять людей, читать проверки состояния и объяснять сбои теми же командами, что использовали бы вы.

## Познакомьте агента с Meridian

Попросите агента выполнить это до любых других действий:

```bash
meridian help agents
```

Команда выводит краткое руководство для агентов в формате Markdown: что делает Meridian, как устроен флот, где хранится его состояние, правила безопасной работы с CLI, коды выхода и типичные задачи. То же руководство доступно на [getmeridian.org/agents.md](https://getmeridian.org/agents.md).

Чтобы закрепить это насовсем, добавьте строку в инструкции для агентов вашего проекта (`AGENTS.md`, `CLAUDE.md` или аналог в вашем инструменте):

```markdown
Наши прокси-серверы управляются через Meridian. Перед работой с ним выполните `meridian help agents`.
```

## Что CLI даёт агентам

- **Никаких вопросов.** Команды, которые что-то меняют, принимают `--yes`. Мастеру `setup` нужен терминал, поэтому агенты используют `deploy`, `node add`, `relay add` и `client add` либо `setup --intent FILE --yes`.
- **JSON-конверты.** Команды с `--json` выводят в stdout один конверт `meridian.output/v1`, в том числе при ошибках. Прогресс и предупреждения идут в stderr.
- **Контракты.** `meridian api commands` перечисляет все команды с машиночитаемым контрактом; `meridian api schema NAME` выводит его JSON Schema.
- **Осмысленные коды выхода.** `0` — успех, `2` — ошибка пользователя, `3` — не хватает данных (SSH, панель или локальное состояние), `4` — завершённая проверка нашла проблемы. Подробности по каждой команде — в [справочнике CLI](/ru/cli-reference/).
- **Сначала просмотр, потом изменение.** `meridian plan` показывает, что изменится, а `meridian apply --yes` применяет ровно это.

## Что документация даёт агентам

- **Каждая страница в виде Markdown.** Добавьте `.md` к адресу страницы, например [/ru/relay.md](/ru/relay.md). В `<head>` каждой страницы также есть ссылка на её Markdown-версию.
- **Кнопки «Копировать страницу» и «Открыть в».** Под заголовком каждой страницы можно скопировать её как Markdown или открыть в ChatGPT или Claude.
- **llms.txt.** [/llms.txt](/llms.txt) — индекс документации для языковых моделей, а [/llms-full.txt](/llms-full.txt) — вся документация в одном файле.

## Не выносите секреты в чат

Страницы подключения и URL подписок дают доступ к вашим серверам любому, у кого они есть. Руководство для агентов велит передавать каждую ссылку только тому, кому она предназначена, и не раскрывать пароль панели, если вы сами не попросите. Не вставляйте ссылки в чат, который вы делите с другими. `meridian doctor` формирует отчёт с вымаранными секретами, которым можно безопасно делиться.
