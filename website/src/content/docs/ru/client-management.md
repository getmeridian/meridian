## Добавить клиента

```
meridian client add alice
```

Это даёт "alice" её собственный ключ и выводит две вещи для обмена:

- **Ссылка на страницу подключения** с QR кодом — самый простой способ отправить
- **URL подписки** для прямого импорта в приложение Xray/V2Ray

Добавьте нескольких человек сразу:

```
meridian client add alice bob charlie
```

Клиенты принадлежат вашему целому флоту, не одному серверу. Каждый выход и ретранслятор, который у вас есть, показывается в их подписке.

### Что видит получатель

Страница подключения построена из подлинной подписки человека, поэтому она перечисляет точно пути, которые получают его приложения: прямые выходы, ретрансляторы и Hysteria2 при включении. Она имеет:

- Пошаговые инструкции по установке приложения (v2RayTun, v2rayNG, Hiddify или v2rayN)
- QR код для каждого пути подключения
- Однокасание "Открыть в приложении" ссылки

Отправьте ссылку через любой мессенджер. Получатель открывает её, устанавливает приложение, сканирует QR код и подключается.

## Показать детали подключения

Чтобы снова поделиться ссылками клиента:

```
meridian client show alice
```

Это выводит страницу подключения и URL подписки, плюс статус, трафик и когда клиент был последний раз виден. Если страница отсутствует (например, загрузка не удалась), переопубликуйте её:

```
meridian client show alice --repair-page
```

## Перечислить клиентов

```
meridian client list
```

Показывает каждого клиента со статусом, трафиком, временем создания и последним видением.

## Приостановить и возобновить клиента

```
meridian client disable alice
meridian client enable alice
```

`disable` отключает клиента немедленно; `enable` позволяет им вернуться с теми же ссылками.

Отключение временное: следующее применение включает каждого объявленного клиента. Apply запускается для `meridian apply`, переразворачивания и когда вы добавляете клиентов, узлы или ретрансляторы. При необходимости отключите снова после них.

## Удаление клиента

`meridian client remove NAME` удаляет клиента окончательно: его ссылки перестанут работать и его страница подключения будет удалена. Флот сохраняет минимум одного клиента. Не удаляйте пользователей в панели Remnawave напрямую — Meridian воссоздаёт любого клиента, который осталась в топологии, при следующем применении.

## Ссылки подписки

URL подписки выглядят как `https://198.51.100.10/<page-path>/sub/<id>`. Они находятся под путём страницы подключения; админ-панель Remnawave остаётся на отдельном секретном пути, который общие ссылки никогда не раскрывают.

Приложения обновляют подписки самостоятельно, поэтому когда вы добавляете выход или ретранслятор, клиенты берут его без новой ссылки.

## Где находятся данные клиента

Учётные записи клиентов (ключи, статус, трафик) живут в базе данных панели Remnawave на сервере контроль-плана. Список клиентов, которыми управляет Meridian, является частью вашей топологии в `~/.meridian/cluster.yml`. Команды client используют API панели и не требуют SSH; публикация страницы подключения использует SSH к серверу контроль-плана.

## Веб-панель

[Remnawave](https://remna.st/) админ-панель показывает трафик, пользователей и узлы в браузере. Её URL и админ-логин находятся в разделе `panel` из `~/.meridian/cluster.yml`, и deploy выводит URL как "Remnawave panel (advanced)".

Используйте панель для просмотра; используйте Meridian для изменения вещей. Meridian восстанавливает пользователей, хостов и шаблоны, которыми он управляет, при следующем применении, и `meridian plan` показывает любую разницу первой.
