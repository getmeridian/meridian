## Что добавляет режим домена

Режим домена расширяет автономную установку тремя компонентами:

1. **nginx stream SNI маршрутизация** — маршрутизирует трафик домена к nginx http вместе с трафиком Reality к Xray
2. **nginx TLS** — сертификаты управляются acme.sh (Let's Encrypt) для вашего домена
3. **Входящее подключение VLESS+WSS** — устаревший резервный путь через CDN Cloudflare (в качестве дополнительного транспорта предпочтительнее XHTTP)

WSS-соединение маршрутизируется через CDN Cloudflare, поэтому продолжает работать, даже если IP-адрес сервера заблокирован: диапазоны IP Cloudflare используются слишком широко, чтобы блокировать их целиком. WSS сохраняется для обратной совместимости; в новых развёртываниях в качестве дополнительного транспорта рекомендуется XHTTP.

## Развернуть с доменом

```
meridian deploy 198.51.100.10 --domain proxy.example.com
```

## Настройка Cloudflare

**Следуйте этому точному порядку** чтобы избежать проблем с TLS сертификатами:

1. Добавьте ваш домен в Cloudflare, создайте **A запись** указывающую на IP сервера
2. Держите облачный значок **серым** ("DNS only") — не включайте проксирование пока
3. Запустите `meridian deploy` — acme.sh получит TLS сертификат автоматически
4. Переключитесь на **оранжевое облако** (Proxied)
5. Настройте SSL/TLS → **Full (Strict)** и Network → **Enable WebSockets**

> **Важно:** acme.sh получает сертификаты через HTTP-01 challenge на порту 80. Если "Always Use HTTPS" Cloudflare активна, это нарушит challenge. Отключите его или добавьте page rule для `/.well-known/acme-challenge/*`.

> **Ещё важно:** в режиме домена размещённая страница подключения, скрытый интерфейс администратора Remnawave и путь страницы подписки обслуживаются с того же имени хоста. После переключения записи в orange-cloud эти страницы тоже проходят через Cloudflare. Отключите на этом имени хоста функции Cloudflare, которые внедряют скрипты или изменяют HTML (например Website Analytics / RUM), потому что страница Meridian намеренно использует строгую CSP без внешних зависимостей. Если страница перестала открываться при проксировании, временно верните запись в режим DNS only и проверьте, исчезла ли проблема.

## Ссылки подключения

С режимом домена пользователи получают три варианта подключения:

| Протокол | Приоритет | Маршрут |
|----------|-----------|--------|
| Reality | Первичный | Прямое подключение к IP сервера |
| XHTTP | Альтернативный | Через nginx на порту 443 |
| WSS | Устаревший резервный | Через CDN Cloudflare |

Пользователям следует сначала попробовать Reality (самый быстрый вариант), затем XHTTP, а WSS использовать только в крайнем случае, если оба варианта не работают, например из-за блокировки IP.
