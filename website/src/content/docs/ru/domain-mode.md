## Что даёт режим домена

```
meridian deploy 198.51.100.10 --domain vpn.example.com
```

Даже без домена выход предлагает Reality, а также XHTTP и Hysteria2 по IP-адресу сервера. Собственный домен меняет две вещи:

- **XHTTP** переезжает на ваш домен, и там же добавляется **WSS** — с сертификатом Let's Encrypt, который Meridian выпускает и продлевает автоматически (через acme.sh)
- Когда домен проксируется через Cloudflare, оба маршрута идут через CDN Cloudflare и продолжают работать, даже если IP вашего сервера заблокирован

Панель и страницы подключения остаются на IP-сертификате сервера; домен используется только для прокси-маршрутов.

Hysteria2 на UDP/443 тоже переходит на сертификат домена (см. [Hysteria2 и Cloudflare](#hysteria2-и-cloudflare)); `--no-hysteria2` отключает его.

## Настройка Cloudflare

**Соблюдайте этот порядок**, чтобы избежать ошибок при выпуске сертификата:

1. Добавьте домен в Cloudflare и создайте **A-запись**, указывающую на IP вашего сервера
2. Оставьте значок облака **серым** («DNS only»)
3. Запустите `meridian deploy 198.51.100.10 --domain vpn.example.com` — Meridian выпустит сертификат
4. Переключите запись на **оранжевое облако** («Proxied»)
5. Установите режим SSL/TLS **Full (Strict)** и включите **WebSockets** (в разделе Network)

После завершения `deploy` ещё раз напомнит эти шаги.

> **Важно:** сертификат выпускается через HTTP-проверку на порту 80. Настройка «Always Use HTTPS» в Cloudflare ломает эту проверку — отключите её или добавьте исключение для `/.well-known/acme-challenge/*`.

## Ссылки для подключения

Подписка и страница подключения каждого клиента содержат все доступные маршруты:

| Маршрут | Как идёт трафик | Когда выручает |
|------|-------|---------------|
| Reality | Напрямую на IP сервера | Основной — самый быстрый |
| XHTTP | Через ваш домен (через Cloudflare при включённом проксировании) | Reality заблокирован или замедляется |
| WSS | Через ваш домен (через Cloudflare при включённом проксировании) | IP сервера заблокирован |
| Hysteria2 | Напрямую на IP вашего сервера по UDP/443 с сертификатом домена | Нестабильные сети или сети с высокой задержкой, либо когда заблокированы все маршруты по TCP |

Приложения с поддержкой подписок Xray JSON, Mihomo или sing-box переключаются между маршрутами автоматически, если один перестаёт работать. Остальные приложения показывают каждый маршрут отдельной строкой.

## Hysteria2 и Cloudflare

Hysteria2 подключается к IP вашего сервера напрямую по UDP, а домен использует только для TLS-сертификата, поэтому продолжает работать при включённом проксировании в Cloudflare (сам Cloudflare такой UDP-трафик не пропускает). Обфускация salamander делает пакеты похожими на случайный шум, а не на QUIC. Там, где UDP заблокирован, приложения переключаются на TCP-маршруты, идущие выше в списке.

## Добавление домена позже

Запустите команду развёртывания ещё раз, добавив `--domain`. Существующие ссылки Reality продолжат работать. Чтобы позже убрать домен, выполните повторное развёртывание без `--domain`: маршруты XHTTP на домене и WSS будут удалены, а подписки обновятся.
