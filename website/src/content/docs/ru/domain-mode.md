## Что даёт режим домена

```
meridian deploy 198.51.100.10 --domain vpn.example.com
```

Без собственного домена выходной сервер уже предоставляет Reality, а также XHTTP и Hysteria2 по IP-адресу сервера. Подключение вашего домена даёт два преимущества:

- **XHTTP** переносится на ваш домен, и там же добавляется **WSS** — с TLS-сертификатом Let's Encrypt, который Meridian выпускает и автоматически продлевает через acme.sh
- После включения проксирования домена в Cloudflare оба этих способа работают через сеть CDN Cloudflare — а значит, остаются доступными даже при прямой блокировке IP-адреса вашего сервера

Сервис управления, веб-панель и страницы подключения при этом остаются на IP-сертификате сервера; домен используется исключительно для маршрутов VPN.

Протокол Hysteria2 на порту UDP/443 также переходит на сертификат вашего домена (см. [Hysteria2 и Cloudflare](#hysteria2-и-cloudflare)); отключить его можно флагом `--no-hysteria2`.

## Настройка Cloudflare

**Выполняйте шаги именно в таком порядке**, чтобы выпуск сертификата прошёл без ошибок:

1. Добавьте домен в панель Cloudflare и создайте **A-запись**, указывающую на IP-адрес вашего сервера
2. Оставьте значок облака **серым** (режим «DNS only», без проксирования)
3. Запустите `meridian deploy 198.51.100.10 --domain vpn.example.com` — Meridian выпустит сертификат для домена
4. Переключите значок облака у A-записи на **оранжевый** (режим «Proxied»)
5. В разделе SSL/TLS выберите режим **Full (Strict)**, а в разделе Network включите поддержку **WebSockets**

По завершении настройки команда `deploy` ещё раз выведет эту памятку в терминале.

> **Важно:** сертификат выпускается с помощью HTTP-проверки на порту 80. Если в Cloudflare включена функция «Always Use HTTPS», проверка не пройдёт — отключите её или добавьте правило-исключение для пути `/.well-known/acme-challenge/*`.

## Способы подключения в подписке

В подписке и на странице подключения каждого пользователя появятся все настроенные маршруты:

| Способ | Как идёт трафик | Когда помогает |
|------|-------|---------------|
| Reality | Напрямую на IP-адрес сервера | Основной и самый быстрый способ |
| XHTTP | Через ваш домен (и через Cloudflare при включённом проксировании) | Когда Reality блокируется или замедляется |
| WSS | Через ваш домен (и через Cloudflare при включённом проксировании) | Когда IP-адрес сервера полностью заблокирован |
| Hysteria2 | Напрямую на IP-адрес сервера по UDP/443 с сертификатом домена | При слабом канале и высокой потере пакетов или при блокировке всех TCP-маршрутов |

Приложения, использующие профили Xray JSON, Mihomo или sing-box, переключаются между способами подключения автоматически. Остальные приложения отображают каждый способ как отдельный сервер в списке.

## Hysteria2 и Cloudflare

Hysteria2 подключается к IP-адресу вашего сервера напрямую по протоколу UDP, а доменное имя использует только для проверки TLS-сертификата. Благодаря этому он продолжает работать даже тогда, когда для A-записи включено проксирование в Cloudflare (сам прокси Cloudflare произвольный UDP-трафик не пропускает). Обфускация salamander маскирует пакеты под случайные данные, чтобы DPI не распознал в них QUIC. В сетях, где оператор блокирует UDP целиком, приложения автоматически переходят на TCP-способы, расположенные выше в подписке.

## Как подключить или отключить домен позже

Чтобы добавить домен к уже работающему серверу, запустите команду развёртывания повторно с флагом `--domain`. Ранее выданные ссылки Reality продолжат работать без изменений. Чтобы отказаться от домена, выполните команду развёртывания без `--domain`: маршрут WSS будет удалён, XHTTP и Hysteria2 вернутся на IP-сертификат сервера, а подписки пользователей обновятся автоматически.
