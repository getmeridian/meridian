Self-hosted proxy tools

Start from what you need

The tools differ less in protocols than in who does the server work.

Many protocols and per-user controls in a browser→3x-uiweb panel for Xray-core
Every Remnawave knob, your own reverse proxy and domain→Remnawaveassembled by hand
Setup from a desktop app, WireGuard-family protocols→Outline or Amneziaapp-first
One Reality server for a few people→reality-ezpzinstall script, no web panel
Reality, XHTTP, Hysteria2, and CDN fallback set up correctly on one or many servers, with relays and a reviewed plan for every change→MeridianCLI that builds a Remnawave fleet

Five questions that separate them

What you install · who sets up certificates, firewall, and 443 · how users get connected · several servers? · can you see a change before it happens?

Where Meridian is the wrong choice

You need VMess, Trojan, Shadowsocks, WireGuard, or OpenVPN · the server hosts other services · you'd rather not use a terminal.
