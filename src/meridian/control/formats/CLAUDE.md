# control/formats — Subscription documents for every client app

## Design decisions
- **Subscriptions follow the golden corpus** — `formats/` renders Base64, Xray JSON, Mihomo, Stash, sing-box, and `/info` status JSON by filling `compiler/delivery.py`'s templates; `formats/selector.py` picks by suffix, then Accept, then User-Agent. `tests/test_control_subscription_corpus.py` diffs every corpus request, each deliberate fix a named row (plain Clash/Stash get Meridian's Mihomo, Hiddify sing-box, an empty User-Agent Base64; no panel security headers). WSS, which no capture holds, follows Remnawave 3.4.5's generators field for field (`test_wss_entries_match_remnawave_generators`).
- **Xray JSON deliberately extends the corpus** — it is a list: "Automatic" stays first, followed by one shared-routing profile per primary endpoint and the existing isolated fingerprint-copy groups (one config per copy fingerprint).
- **Renderer takes plain values** — `SubscriptionUser` (UUID, short ID, status `active|disabled|limited|expired`, expiry, traffic and its reset strategy) and `ClientEndpoint`s, where `ClientEndpoint.fingerprint_copy` marks copies; a suspended user gets Remnawave's status placeholder entries in every format. `ServiceSettings.public_url` feeds `support-url`/`profile-web-page-url`, and Hysteria2 auth is the VLESS UUID, as Remnawave delivered it.
- **Translated status labels** — `status_remarks.py` translates only the fixed labels; status codes and inert credentials stay stable in every language.
- **Suffixes come from one table** — derive subscription suffix routing from `formats.selector.SUFFIX_FORMATS`; aliases override Accept and User-Agent, and Stash retains its own dialect.
- **Stale-client nudge** — `stale_clients.py` maps a User-Agent to one inert entry (`outdated` v2rayNG below 1.9.17, `abandoned` NekoRay), each rule with its documented reason; it is read per request, stored nowhere, last in every format, and the preview reports it as `stale_client`.

## Pitfalls
- **Every structured renderer gets the routing policy** — pass the topology's `client_routing` to each one, including Xray fingerprint groups and Stash.
- **Names before filters** — sort endpoints once, then allocate unique presentation names before filtering, reserving generated groups and the direct/reject labels; primary filters and fingerprint groups preserve that order because generated numeric suffixes sort differently. Preserve original suffix-shaped remarks, and use the same names in proxies, tags, and copy exclusions.
- **Availability notices are inert and shared** — Xray availability checks primary endpoints, so fingerprint copies alone must show the same inert availability notices as Mihomo and sing-box. Empty supported endpoint sets use inert availability placeholders in all four locales, with existing status notices taking priority; filter Stash XHTTP and sing-box XHTTP/copies before checking availability.
- **Never compress or send Referrer-Policy on `/sub/`** — nginx gzips JSON/Base64 (YAML stays plain, as `gzip_types` has none) and adds its own Referrer-Policy; the panel's duplicate was a corpus defect.
- **A fingerprint copy without `fingerprint_copy` lands in the primary balancer and failover groups** — that mixes fingerprints toward one server (TSPU escalates); copies group per fingerprint too (`copy_groups()`: a Safari path's Chrome and Firefox copies once shared one balancer), and sing-box omits copies entirely.
- **Mihomo and Stash read YAML 1.2, PyYAML writes 1.1** — dump through `mihomo._Yaml12SafeDumper`, which quotes strings 1.2 resolves as numbers or booleans; a random short ID like `12e34567` once became a float and Mihomo refused the document (System Lab caught it by chance).
- **Hysteria2 has two spellings** — `hysteria2` in Meridian keys and URLs, but protocol/network `hysteria` plus version `2` in Xray configs, as in Remnawave profiles.
- **Stash spells fields its own way** (`sni`, Hysteria2 `auth`) and has no `exclude-filter` or `GEOIP,private`; Remnawave's Stash and Clash answers had no failover at all.
- **The nudge never replaces or reorders real entries** — it joins only the "Meridian" selector or sing-box selector, never the fallback or urltest group; status, availability, and device-limit placeholders drop it, and an app without a documented threshold stays out of the table (Happ's GitHub builds share its store User-Agent).
